# 护眼操 · 跟随光球（Snow App 脚本插件）

一个注入 Snow 桌面窗口的客户端 UI 脚本：点开后出现一颗柔光球，用户用**眼球**跟着它运动，配合远近调焦与远眺放松，缓解长时间看屏幕带来的睫状肌紧张。

- 形态：脚本插件（单文件 `.user.js`），不是面板插件
- 时长：一套 90 秒，可随时暂停退出
- 特点：**提醒文字贴着光球走**，不需要把视线移到屏幕边缘

## 入口在哪（找不到就看这里）

装好后有三个入口，任选其一：

| 入口 | 位置 | 说明 |
| --- | --- | --- |
| **顶栏按钮（推荐）** | 窗口顶部工具栏的右侧，眼睛图标 + 「护眼操」文字 | 常驻入口，平时用这个 |
| **右下角浮动按钮** | 窗口右下角，圆角胶囊「护眼操」 | 只有顶栏插槽不可用时才会出现 |
| **脚本菜单命令** | 插件 → 插件列表 → 脚本插件 → 本脚本所在行的菜单 | 兜底入口，任何情况下都能打开 |

首次安装后，入口按钮下方会自动弹出一个气泡提示「点这里开始护眼操」，约 9 秒后消失；打开过一次后不会再打扰。

## 为什么这样做（护眼原理）

长时间近距离看屏幕时，睫状肌持续收缩、晶状体保持凸起状态，容易出现酸胀、聚焦变慢。这套操把三种经典的眼部训练合成一段 90 秒的引导：

| 阶段 | 时长 | 训练内容 | 作用 |
| --- | --- | --- | --- |
| 准备 | 3.2 s | 坐正、放松肩膀，视线落在光球上 | 进入专注状态，避免头跟着动 |
| 平滑追踪 | 24 s | 光球沿 ∞ 形缓慢移动，视线黏住它 | 训练眼外肌的平滑追踪能力，放松眼球 |
| 快速扫视 | 14 s | 光球在屏幕不同位置快速跳转 | 训练扫视（saccade），让眼睛从僵硬的凝视中解放 |
| 远近调焦 | 28.8 s | 光球反复变大 / 变小 | 提醒视线在「看近」与「看远」间交替，锻炼并放松睫状肌 |
| 远眺放松 | 20 s | 光球缩成中心小点 | 20-20-20 法则：看向 6 米外，配合眨眼 |

关键点：**只动眼球，不转脖子**。转脖子并不会训练到睫状肌，反而会让颈部紧张。

## 提示跟随光球

用户的注意力始终在光球上，所以所有关键提示都做成了**贴着光球移动的悬浮卡**：

- 始终显示两行：琥珀色的「只动眼球 · 别转脖子」+ 当前阶段的动作指令；
- 悬浮卡默认在光球下方，靠近屏幕底部时自动翻到上方，左右会自动贴边收拢，不会跑出屏幕；
- 阶段指令会随课程切换，例如「视线跟着光球，头不要动」「光球跳到哪，眼睛就看到哪」「看远 · 视线越过屏幕看向远处」；
- 屏幕顶部只保留很淡的阶段名，底部保留激励语、进度条与倒计时，作为余光信息。

## 使用步骤

1. 点顶栏右侧的「护眼操」按钮（找不到时看右下角浮动按钮）。
2. 开始卡片会显示今日次数、连续天数与累计次数，并提示下次入口位置。
3. 点「开始护眼操」，按光球旁的提示跟随光球。
4. 过程中按 `Esc` 或右上角 `×` 会暂停，可选择继续或结束。
5. 完成 90 秒后记录一次，并给出鼓励文案。

激励语每 7 秒轮换一条，全部写在脚本的 `COPY` 字典里，可以自行增删。

## 安装

### 方式一：插件页面导入

插件 → 插件列表 → 脚本插件 → **导入文件**，选择 `eye-care-ball.user.js`，保存即生效。

### 方式二：命令行 / 让 AI 安装

```text
config-set scope=userscripts key="new" value={sourcePath: "D:/GitHub/snow-app-plugins/plugins/eye-care-ball/eye-care-ball.user.js"}
```

安装后可在「插件列表 → 脚本插件」中启停、编辑、删除。

## 数据与隐私

- 只使用 `GM_getValue` / `GM_setValue` 保存本地统计（总次数、连续天数、每日次数）与「入口提示是否看过」。
- **不读取任何应用元数据**，不发起任何网络请求，因此没有 `@snow-privacy` 声明。
- 脚本运行在默认的**沙箱档**（独立隔离世界），只通过 DOM 与 `GM_*` 工作，不触碰 `window.snow` 的文件 / 终端等能力。

统计结构（`ecb.stats.v1`）：


## 自定义

| 想改什么 | 改哪里 |
| --- | --- |
| 各阶段时长 | `TIMING`（总时长由各段自动相加） |
| 光球轨迹、振幅 | `computeBall()` 中的 pursuit 分支 |
| 扫视落点节奏 | `computeBall()` 中的 `hold = 900` |
| 跟随提示的位置 | `placeFollowLabel()`（下方 → 上方翻转、贴边收拢） |
| 入口按钮文案 | `COPY` 里的 `launcherLabel` / `entryHint` / `entryTip` |
| 配色 | `CSS` 里的 `#7ff0d4` / `#3fc9b0` 等渐变色 |
| 文案与激励语 | `COPY["zh-CN"]` / `COPY.en` |

修改后重新导入或编辑保存即可，脚本会重新注入。

## 注意

- 这是放松练习，不是医疗手段。眼部有疾病、术后恢复期或出现疼痛、闪光感等异常，请先咨询医生。
- 眩晕、恶心或不适时立刻停止；练习时保持正常眨眼和呼吸。
- 建议每 20–30 分钟屏幕工作后做一组，而不是等到眼睛已经酸痛。
